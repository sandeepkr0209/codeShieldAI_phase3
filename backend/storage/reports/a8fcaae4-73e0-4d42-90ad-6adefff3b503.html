CWE-494 / A05:2021 - Security Misconfiguration
Description
The CI workflow contains a step that pipes the output of `curl` (or `wget`) directly into a shell interpreter (`| bash`). This allows arbitrary code from the remote URL to be executed on the CI runner without verification.
Impact
If the remote server is compromised or the URL is hijacked, an attacker can execute malicious commands in the CI environment, potentially stealing secrets, modifying code, or compromising downstream deployments.
Remediation
Download the script to a file first, verify its integrity using a checksum or digital signature, and only then execute it. Prefer using trusted package managers or pinned versions. Avoid piping untrusted network data directly to a shell.
